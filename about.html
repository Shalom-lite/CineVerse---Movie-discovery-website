About CineVerse

Discover your next favorite movie. CineVerse is a modern, lightweight movie discovery platform that proves how far clean HTML, CSS and vanilla JavaScript can go.

CineVerse started as a simple question: what does a movie discovery experience look like when it is built without heavy frameworks? The answer is a fast, accessible catalog of fictional films where every poster, filter and detail page is powered by hand-written code. No build tools, no dependencies — just the web platform.

🎬 What you can do here

  • Browse trending and popular movies
  • Search instantly by title or cast member
  • Filter by ten genres and sort four ways
  • Open full details with ratings and release dates
  • Jump to trailers on YouTube in one click

💻 Built with

  • Semantic HTML5 for structure and accessibility
  • Modern CSS: variables, grid, flexbox, animations
  • Vanilla JavaScript for all movie logic
  • A local JSON dataset — no APIs required
  • PHP only for the newsletter & contact forms

🎥 About the movies

Every film, actor and rating in CineVerse is fictional demo content created for this project. Nothing here represents real productions, people or facts, and all artwork is original SVG generated for the site.

⚡ Design principles

  • Cinematic dark theme with a single violet accent
  • Fully responsive from 320px to widescreen
  • Keyboard friendly with visible focus states
  • Reduced-motion support for comfort
  • Fast: zero frameworks, lazy-loaded images
